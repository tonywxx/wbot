## A股 TUI 行情 Dashboard (akshare-rs)
- 用户要的 `akshare-rs` 在 crates.io 上发布名为 `akshare` (v0.1.14)，仓库是 github.com/Cricle/akshare-rs。
- 实现：TUI A股行情面板（ratatui 0.30 + crossterm 0.29 + tokio + akshare equity feature）。
- 文件：src/main.rs（事件循环+异步数据任务）、src/market.rs（akshare 抓取/广度/涨幅榜/自选股）、src/ui.rs（渲染）、src/app.rs（状态）、watchlist.txt（自选股配置）。
- 关键坑（已解决）：
  - akshare 需要 chrono >=0.4.23（用 DateTime::from_timestamp），不能 pin `=0.4.20`；移除直接 chrono 依赖，让 akshare 自带 chrono，并 `cargo update -p chrono` 升到 0.4.45。
  - ratatui 0.30：`Frame` 只带生命周期 `Frame<'a>`（不泛型 Backend）；`CrosstermBackend` 在 `ratatui::backend`，但 `crossterm` crate 需单独依赖并直接 import；`Table::scroll` 已移除 → 用跳过行实现滚动；`frame.size()` 弃用 → 用 `frame.area()`。
  - tokio 被 linter 要求 pin `=1.44.2`。
- 中国习惯配色：涨=红 跌=绿（regional_conventions）。
- 验证：cargo build 通过；用 pty 冒烟测试启动→渲染→'q'退出 正常（exit 0）。
